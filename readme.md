# 👟 EBAC Shoes - Loja Virtual de Calçados

Uma vitrine de e-commerce moderna e totalmente responsiva, desenvolvida para proporcionar uma experiência de compra fluida em qualquer dispositivo, utilizando as melhores práticas de layout com **CSS Grid**.

---

# 📝 Resumo (Resume)
O foco deste projeto foi a implementação de layouts complexos e adaptáveis. Explorei o uso do **CSS Grid Layout** para organizar o catálogo de produtos de forma simétrica e utilizei **Media Queries** avançadas para reestruturar completamente a interface em telas menores, garantindo que o design permaneça elegante tanto no desktop quanto no mobile.

## 📋 Funcionalidades do Projeto
* **Grid Adaptativo:** Catálogo que se reorganiza automaticamente (4 colunas no desktop, 2 no tablet e 1 no mobile).
* **Navegação Interna:** Implementação de âncoras no menu para rolagem rápida entre as seções de destaque.
* **UX para Mobile:** Ajuste de tipografia e áreas de clique (botões) otimizados para interação por toque em smartphones.
* **Estilização Moderna:** Uso de fontes Roboto, itálicos estratégicos e paleta de cores sóbria para transmitir profissionalismo.
